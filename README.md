# 新石器L4技术与团队规划网页

中文面试答辩报告，包含12–18个月技术规划、同期12个月团队建设、国产智驾硬件比较及可调TCO模型。当前 **V1.3，更新于2026-11-06**。

章节顺序：战略摘要 → TCO与竞争优势（含国产硬件与BOM）→ 技术架构 → 技术路线 → 团队建设 → 验收风险 → 依据与假设 → 行业与方法。TCO章节内按“标注预算 → 国产硬件与BOM → 联动整车账”排列。“借鉴方法，验证自己的收益”保留在最后。

## 打开网页

直接用浏览器打开仓库根目录的 `index.html`。页面使用原生HTML/CSS/JavaScript、本地SVG，不依赖网络资源、包管理器、构建工具或后端。外部资料链接需要联网访问。

也可在本目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080`。退出时按 Ctrl+C。

## 联动交互与核算边界

- 接管参数采用“现状 / 方案”两列：工资、排班系数、人车比、MPCI、平均处理时长和现场救援。两边工资与排班可分别调整；当前人车比固定为用户提供的1:20。
- 推演人车比取拟验证上限与负荷等效上限的较小值。后者为 `20 × 方案MPCI / 现状MPCI × 现状处理时长 / 方案处理时长`，假定ODD与平均运行速度不变。这是工作量情景，不是已批准的排班容量；峰值并发、应急和响应时效需另外验证。
- 单车年人工费 `12 × 月雇主全成本 × 排班系数 / 人车比`，加救援后回填协助行。保费与未覆盖净损失回填保险行；MPCI不自动降低保费。
- 选择演示、单6P、双6M或单6M方案；完整域控报价与其他套件形成智驾BOM，再与非智驾BOM合并。功耗回填电费，适配NRE归入研发预算。实际国产候选报价、功耗和NRE默认留空，不产生虚假供应商价格或排名。
- 客户运营账：BOM乘采购系数估算购置价，使用实际合同应校准该系数；在线软件、通信及云服务按收费计入，已覆盖的标注与研发不重复追加。
- 自营资源账：出厂成本年化，在线服务按实际资源计入，同时加入标注、训练和适配的管理分摊。不含对外订阅收费，也不是完整企业利润表。
- 标注按初期数量与年度增量数量建账；初期投入I含硬件适配，后续增量R按年归集。单车年研发分摊为 `(I / 分摊年限 + R) / 实际受益活跃车辆`，不用未来百万辆作分母。
- 3D默认16元/帧，不再叠加0.2–0.3元/object；barrier默认0.8元/帧，保留两轮100%质检。2D和DCT没有精确单价，默认数量0仅表示演示未纳入；数量非零必须补齐价格，不能凭空采用“行业均价”。
- 原非智驾车辆、智驾硬件两项年化费用合并为“整车折旧与资金成本”；智驾归属占比仍使用智驾硬件部分计算，不将整车费用都归为智驾。默认客户账该行21,600 → 18,240元，自营账18,000 → 15,200元，总费用不变。
- 每一费用行写明“修改位置”；联动项提供源参数跳转，折叠的源参数区会自动展开。维修和场站费用标注本行直接修改。
- 只读费用行由源参数回填；维修和场站费用直接录入，避免重复归集。竞品参数默认未知，填入同口径数据后计算优势、敏感性及40%门槛差距。切换账本自动清空竞品数据。
- “重置全部联动参数”恢复所有成本源、账本、硬件选择与未知竞品参数。参数不上传、不持久保存。零产出、负数或缺失报价暂停结果；研发账缺失仅阻止自营资源账，客户账仍可按完整的合同收费计算。
- 保留技术阶段切换、七类团队角色展开及打印；手机宽表可横向滚动。打印会展开详细内容与全部阶段，结束后恢复。

## 默认演示与人工复算

主指标 = 单车年化总费用 / 年度有效载货公里。有效公里按完成配送的基准OD距离计量，空驶、绕行和失败任务不增加产出；比较保持同车型、载货标准、ODD和SLA。修改产出仍需同步复核能耗、磨损、人力等费用。

以下均为演示假设，不是实际报价或经营成果：

| 账本 | 现状年度费用 | 方案年度费用 | 现状单位成本 | 方案单位成本 |
| --- | ---: | ---: | ---: | ---: |
| 客户运营账 | 58,140元 | 47,420元 | 1.938 | 1.264533… |
| 自营资源账 | 50,340元 | 41,218.8元 | 1.678 | 1.099168 |

单位成本为元/有效km；对应产出30,000与37,500有效km/年。默认竞品未知，不自动宣称40%领先。

- 人工：两边月成本10,000元、排班系数1，1:20 → 推演1:40，年人工费6,000 → 3,000元；加救援600 → 400元后，协助行6,600 → 3,400元。
- 碰撞：保费4,000 → 3,900元，加未覆盖损失500 → 400元，保险行4,500 → 4,300元。
- 硬件：智驾套件30,000 → 22,000元，非智驾BOM60,000 → 54,000元，整车BOM90,000 → 76,000元；客户采购系数1.2、寿命5年、残值与资金率0。域控80 → 60W、年通电3,000小时、电价1元/kWh，电费240 → 180元。
- 研发：初期标注168,000＋初期训练等200,000＋NRE100,000 = I 468,000元；年度增量标注32,800＋训练等50,000 = R 82,800元。首年预算550,800元；分摊3年、实际受益1,000辆，方案年分摊238.8元/车。客户账研发行0，自营账238.8，避免与订阅重复。
- 人工填入客户账竞品60,000元/30,000有效km后，优势 `1 − (47420 / 37500) / 2 ≈ 36.7733%`，距离40%门槛还需降0.064533…元/有效km；竞品再降10%/20%时优势约29.7481%/20.9667%。这些是公式校验情景，不作为真实竞品数据保存。
- 瀑布图按“年度费用变化 → 有效产出换算”分解，默认客户账指数100 → 81.5617 → 65.2494。硬件折旧与研发管理分摊不等于当期现金支出，不作会计资本化结论。

公开成本参考仍保留：企业采访披露的0.4–0.5元/公里与商业模式假设0.25元/公里，不替代行业均值或有效载货公里成本。DCT定义、bag时长与精确单价没有统一核验依据；保留用户20+元/bag原始输入，不自行换算。来源详见网页。

## 内容边界

- 2026现有3万辆、2027目标10–15万辆、2028目标50–60万辆、2029挑战百万辆，以及已有七类成员背景，均为用户给定前提。
- 40%竞争优势为用户目标；其他KPI、BOM指数、验证车数、关键岗位数量和预算比例均为规划示例，需按内部基线校准。
- 公开来源在网页中就近引用，来源章节含10条官方资料及2条公开采访链接。企业自述不等同独立安全认证；定点、订单、交付、运营和目标不得混用。
- 面试长图只提炼工程经验，未包含个人履历或薪酬，也未将原图复制到公开网页中。
- 本页不是新石器官方发布；未知内部架构、经营数据、团队人数和竞争TCO不作为事实陈述。
